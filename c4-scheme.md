## Участники

- Клиент (Person): пользователь web‑сайта InsureTech, оформляет и просматривает страховки.

- Платёжный сервис (Software System): внешняя платёжная система, через которую проводится оплата страховок; деньги уходят на счета страховых компаний.

- Системы партнёров (Software System): внешние системы партнёров, интегрирующие страховые услуги InsureTech в свои продукты через API.

- Системы страховых компаний (Software System): ИТ‑системы страховых компаний, предоставляющие API для получения актуальных тарифов, андеррайтинга и оформления страховых продуктов.

***

## Граница системы

- Виртуальная машина «InsureTech Prod» — внутри неё развернуты контейнеры с приложениями и БД (кластер Kubernetes в одной зоне доступности).

***

## Внутренние контейнеры и базы данных

1. InsureTech Web
   - Тип: веб‑приложение.
   - Технологии: JavaScript, React.
   - Ответственность: интерфейс для клиентов, подбор и оформление страховок, взаимодействие с backend по REST.

2. core-app
   - Тип: монолитное backend‑приложение.
   - Технологии: Kotlin, SpringBoot.
   - Ответственность:
     - отображение доступных страховых продуктов;
     - оформление заявок на новые страховки;
     - отображение уже оформленных страховок.

3. client-info
   - Тип: сервис управления клиентскими данными.
   - Технологии: Kotlin, SpringBoot.
   - Ответственность:
     - хранение и предоставление клиентских данных core-app для оформления страховок;
     - создание/обновление клиентских данных, если их нет или они изменились;
     - отображение и редактирование данных клиента в личном кабинете.

4. ins-product-aggregator
   - Тип: сервис интеграции со страховыми компаниями.
   - Технологии: Kotlin, SpringBoot.
   - Ответственность:
     - получение информации о страховых продуктах и тарифах от страховых компаний;
     - запрос предложений по ОСАГО для конкретного автомобиля у разных партнёров;
     - предоставление единого API, агрегирующего данные всех страховых компаний.

5. ins-comp-settlement
   - Тип: сервис взаиморасчётов со страховыми компаниями.
   - Технологии: Kotlin, SpringBoot.
   - Ответственность:
     - учёт оформленных страховок для расчёта агентских вознаграждений;
     - раз в месяц отправка перечня оформленных страховок в страховые компании для расчёта выплат.

6. core-db
   - Тип: база данных PostgreSQL.
   - Ответственность: хранение тарифов страховых компаний и заявок клиентов на страховые продукты (отдельная схема данных для core-app).

7. ins-comp-settlement-db
   - Тип: база данных PostgreSQL (используется двумя экземплярами на схеме).
   - Ответственность:
     - хранение данных клиентов, ФИО, паспорт, телефон и прочая информация, необходимая для оформления страховок и взаимодействия со страховщиками;
     - хранение данных об оформленных страховках и условиях взаиморасчётов со страховыми компаниями.
